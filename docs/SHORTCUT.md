# 全局唤起快捷键

工作状态文档：记录目标、设计决定、步骤与验证结果，交给后续接手的人。

## 目标

- 设置「行为」分组的第一个是**全局快捷键**：在任意窗口按下时显示或隐藏启动器；可录制、
  可清除，不显示说明文字。
- 开机自启暂不做，等快捷键稳定后另行处理。

## 设计决定

- 快捷键偏好存 `ui-state.json` 的 `shortcut`（规范形式，如 `Ctrl+Alt+Space`）。
- 用 `mygo.GlobalShortcut` 注册（Windows 为 `RegisterHotKey`，回调在主线程）；应用启动后
  （`WhenReady`）注册，设置里改变时先解绑旧值再注册新值。
- 录制用聚焦的只读 `TextInput` + `OnTextKey` 取 `Key`/`Mods`；普通键要求至少包含 Ctrl、Alt
  或 Super，F1–F12 可以单独使用；Escape 取消，Backspace/Delete 清除。键位映射覆盖字母、数字、
  符号、F1–F12、方向键等 accelerator 支持的键。
- 快捷键行为：主窗口可见且聚焦时隐藏（后台运行开启则隐藏到托盘，否则最小化）；否则
  `showMain()` 并聚焦。
- 托盘「打开」项显示快捷键；更换快捷键后重建托盘菜单。
- 测试替换注册函数，无头环境不调用 MyGo。

## 坑

- 快捷键被其它程序占用时注册失败，保留旧值并提示。
- 应用没运行时快捷键不存在，通常与后台运行一起使用。
