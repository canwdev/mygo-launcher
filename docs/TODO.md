### 静默启动

- [x] 新增命令行参数 `--silent`
  - 启动时不显示主窗口。
  - 后台运行开启：只保留托盘和全局快捷键，与关闭主窗口后的状态一致。
  - 后台运行关闭：窗口保持隐藏；若设置了全局快捷键，仍可用它唤出。
  - 应用已经在运行时，静默启动不改变窗口当前的显示状态。

### 主界面键盘操作

- [x] 选中项
  - 方向键在网格中移动选中项；选中项有可见高亮，并自动滚动到可视区域。
  - 空白格不参与选中，方向键跨过空白落到最近的条目。
  - 上：第一行时切到上一页，否则移到上一行；左：第一个条目时切到上一页，否则移到前一个条目。
  - 下：最后一行时切到下一页，否则移到下一行；右：最后一个条目时切到下一页，否则移到后一个条目。
- [x] 回车：等同于单击选中的条目——程序启动；文件夹打开内容面板；计时器开启时，运行中的程序询问是否停止。
- [x] 页面切换
  - PgUp/PgDn：上一页/下一页。
  - Tab：下一页，循环。
  - Home/End：第一页/最后一页。
  - 1~9：切到第 n 页；页数不足时不动作。
  - 切页后选中新页面的第一个条目，并把页面胶囊滚到可见位置。
  - 鼠标停在页面胶囊上时用键盘切页，悬停延迟过后不会把页面切回去。
- [x] Ctrl+,：打开设置窗口。
- [x] Esc
  - 没有浮层时：后台运行开启则隐藏到托盘，否则最小化。
  - 打开右键菜单、文件夹面板、添加菜单、搜索或对话框时：只关闭浮层，主窗口不动。

  - 键盘导航期间不显示鼠标悬停高亮和悬停才出现的运行时长；指针再次移动后鼠标接管。

  - 按下字母只把选中项移到对应槽位，不启动条目；槽位是空白时不动作。浮层或对话框打开时不生效。

### 实现时采用的默认

- 静默启动且后台运行关闭时，窗口隐藏且不创建托盘；如果设置了全局快捷键，仍可用它唤出。
- `--at-cursor` 在窗口已经在前台时只置前并移动，不像快捷键那样切换隐藏。
- 「回车…打开子菜单」按单击处理：文件夹条目打开内容面板。

### 外观自定义采用的默认

- 设置窗口始终在自定义图标右下角叠齿轮；主窗口、托盘和「关于」用原图。
- `.exe` / `.dll` 只取第一个图标，不提供序号输入。
- 程序图标不提供 SVG；背景只收 png/jpg/jpeg/gif/bmp/webp，按显示器像素尺寸缩到最长边 1280~2560；不透明存 JPEG（质量 90），带透明存 PNG。
- 背景连续铺满主窗口（含顶栏），设置窗口保持现有底色；默认透明度 40%，滑块范围 5%~90%。
